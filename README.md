# 🧠 Jeremiah Krakowski Brain Pack

> Install Jeremiah's complete teaching library into your AI agent — 6,000+ transcripts from WCA training, Thinkific courses, webinars, and YouTube.

---

## Pick Your Platform

### 🤖 Claude Code
**Copy and paste this into your terminal:**
```bash
git clone https://github.com/wcabrainpack/brain ~/.claude/skills/jeremiah-brain-pack
```
That's it. Restart Claude Code and it auto-loads.

---

### 🦾 OpenClaw
**Copy and paste this into your terminal:**
```bash
git clone https://github.com/wcabrainpack/brain ~/.openclaw/skills/jeremiah-brain-pack
```
Restart your OpenClaw session. The skill activates automatically.

---

### 💎 Codex (OpenAI)
**Copy and paste this into your terminal:**
```bash

```
Then add this to your `AGENTS.md` or project root:

See ~/jeremiah-brain-pack/CLAUDE.md for Jeremiah's frameworks and teaching context.

### 🌟 Gemini CLI
**Copy and paste this into your terminal:**
```bash
git clone https://github.com/wcabrainpack/brain ~/jeremiah-brain-pack
```

### 📦 Any Agent (npm install)
```bash
npm install -g https://github.com/wcabrainpack/brain
```
Auto-installs to `~/.claude/skills/` and `~/.openclaw/skills/`.
